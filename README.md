# 위수 협의 로컬 배치 시뮬레이터 v4

`index.html`을 더블클릭하면 됩니다. 인터넷/Node.js/Python/서버가 필요 없습니다.

## v4 변경점
- 대기 슬롯은 항상 정사각형 유지
- 4x6 전장은 크게 유지하면서 화면 폭에 맞춰 유동적으로 변화
- 부가 맹약 필터를 8개/7개 두 줄로 분리
- 맹약 이미지 크기 축소
- 오퍼레이터 목록의 행/초상화/폰트 크기 확대 및 반응형 폰트 적용
- 티어 색상: 1 `#c5c5c5`, 2 `#000000`, 3 `#46efbc`, 4 `#33c9da`, 5 `#f6c60f`, 6 `#e88c1a`
- 격자 도구는 마우스를 누른 동안만 칠해지며, 오퍼레이터 드래그 시작 또는 목록 클릭 시 자동 해제
- 전장 오퍼레이터 우클릭 시 삭제, 방향 기능 제거
- 전장에 놓인 **서로 다른 오퍼레이터만** 맹약 인원수 집계
- 맹약 활성화 인원 충족 전에는 상태 아이콘이 반투명, 충족 시 정상 표시
- 우측 상단 `전체 오퍼 / 배치 정보` 전환 버튼 추가
- `배치 정보`에서는 전장에 실제 배치된 오퍼레이터만 한눈에 확인 가능하며, 중복 배치는 `×N`으로 표시

## 맹약 활성화 인원
핵심 맹약 8종은 모두 3명.
부가 맹약: 정밀2, 신속2, 기민2, 아케인2, 고수2, 조력2, 예견2, 기적2, 투자자3, 기습2, 불굴2, 조화1, 협동방어3, 독행1, 궁극기2.

## 이미지 경로
- 오퍼레이터: `assets/operators/이름.webp`
- 맹약: `assets/covenants/이름.webp`
- 태그: `assets/tags/이름.webp`


## v5 변경
- 벤치 슬롯은 항상 정사각형
- 격자 설정은 드래그 칠하기가 아니라 칸별 클릭 방식
- '배치 가능' 명칭을 '지상 칸'으로 변경
- 전장 오퍼레이터 우클릭 삭제, 방향 기능 없음
- 맹약 집계는 1명 이상인 맹약만 표시
- 동일 오퍼레이터는 맹약 인원에 중복 집계하지 않음
- 예견/기적/투자자에 한해 벤치의 해당 맹약 오퍼레이터도 활성화 인원에 포함
- 벤치 인원은 배치 정보 목록에는 포함하지 않음
- 연막 칸에는 오퍼레이터 초상화 위에 애니메이션 연막 오버레이 표시

- 상단 맹약 현황은 0명 맹약을 숨기고, 이미지/이름/현재 인원만 중앙 정렬로 표시합니다.


## v6 변경
- 연막 칸: 애니메이션 제거, 고정된 뿌연 오버레이
- 언덕 칸: #FFE293 → #FED07B 세로 그라데이션
- 전장/벤치 모두 우클릭으로 오퍼레이터 삭제
- 브라우저 기본 컨텍스트 메뉴 전역 차단
- 독행 맹약: 정확히 1명일 때만 활성, 2명 이상이면 비활성
- 상단 맹약 현황 크기 확대 및 고정 높이
- 우측 맹약/태그 필터와 표 내부 맹약/태그 이미지·글자 약 1.3배 확대


## v7 변경
- 지상 칸 기본색을 #2A3A5B로 변경
- 연막 칸은 지상 칸과 같은 바탕색에 매우 약한 고정 뿌연 효과만 추가
- 전장 상단 맹약 아이콘/이름에 마우스를 올리면 원문 맹약 설명 툴팁 표시
- 필터 논리 변경:
  - 핵심 맹약 내부: OR
  - 부가 맹약 내부: OR
  - 태그 내부: OR
  - 핵심 / 부가 / 태그 그룹 사이는 AND
